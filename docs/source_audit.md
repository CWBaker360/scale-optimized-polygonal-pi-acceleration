# Source Audit

Three source records were supplied.

1. `original_may9_concept_version.pdf` contains the strongest theorem-level
   material, but duplicated a theorem and overstated the constructible
   tripling conclusion.
2. `original_short_archimedes_note.tex` is a two-page position note. Its claim
   that `6 -> 18 -> 54 -> ...` is an exact constructible refinement ladder is
   not valid.
3. `original_symmetry_framework_draft.tex` contains useful exposition but has
   a wrong dyadic three-scale coefficient (`1/64` instead of `1/45`) and an
   unsupported claim that reflection symmetry alone forces a zero linear
   coefficient.

The revised paper retains the valid scale-cancellation and stability results,
corrects these defects, and preserves all original records for provenance.
